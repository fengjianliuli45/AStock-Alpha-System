## 使用规则（强制）

1. **先读后写**：新开策略版本或改参数前，先扫本文件「已沉淀教训」与最近 10 条犯错记录。
2. **犯错必记**：回测翻车、实盘偏差、数据穿越、过拟合、出场漏网等，发现当日追加一条（模板见下）。
3. **禁止静默复活**：被死亡线冻结的策略，不得改参冒充小版本上线；必须新版本号 + 新预注册 + 新回测。
4. **教训可升级**：同一类错误出现 ≥2 次 → 写入「已沉淀教训」，并考虑写进设计文档模块约束。
5. **改设计要挂钩**：若某条教训导致模块规则变更，在记录里写明「已同步到设计 vX.Y / 模块 N」。

## 已沉淀教训（v0.1–v0.5）

### L-001 治理松散比信号错误更致命
- **现象**：参数边看结果边拧；版本约束弱；死亡线不统一。
- **根因**：没有预注册与晋级门，研究过程本身在制造过拟合。
- **对策**：模块 0——参数冻结、版本号、晋级门、死亡线、`trading_enabled` 默认关闭。
- **验收**：任何参数改动 = 新版本；样本外未过晋级门不得实盘。

### L-002 纯量价缺少「值不值得持有」维度
- **现象**：Alpha158 风格量价因子在中线持有上脆弱。
- **根因**：没有 PIT 基本面回答 20–60 天持有质量问题。
- **对策**：模块 4——盈利/成长/估值/健康 + 行业中性化 + 严格 `published_at`。
- **验收**：无 `published_at` 的财务数据不得进评分。

### L-003 只有止损、没有止盈是致命伤
- **现象**：浮盈坐过山车；或长期无收益占用仓位。
- **根因**：出场体系不完整，入场优势被出场吃掉。
- **对策**：模块 8——硬止损 / 时间止损 / 分档止盈 / 跟踪止盈 / 基本面恶化。
- **验收**：任何新策略必须预注册完整出场表，禁止「先上线再补止盈」。

### L-004 不做板块与行业约束会逆水行舟
- **现象**：个股因子尚可，组合仍被错误行业拖死。
- **根因**：A 股行业轮动 alpha 未被显式建模；无行业中性/持仓上限。
- **对策**：模块 2 + 持仓「每板块最多 1 只」+ 行业内排名。
- **验收**：回测报告必须含行业暴露；同行业不得叠两只主动仓。

### L-005 无 Regime 时熊市/恐慌仍满仓挨打
- **现象**：震荡与熊市回撤失控。
- **根因**：假设「策略在所有市场环境都有效」。
- **对策**：模块 1——牛/震/熊/恐慌仓位乘数 + 情绪门控。
- **验收**：压力场景（2015/2018/2024）必须单独报告，而非只看全样本均值。

### L-006 固定调仓日不等于可交易时机
- **现象**：信号日不可买、追高接盘、与回测成交假设不一致。
- **根因**：缺技术确认 gate 与入场阻塞（涨跌停/流动性/停牌）。
- **对策**：模块 5 + 模块 6；中线次日 09:31，阻塞则跳过不得假装成交。
- **验收**：回测引擎必须能产出 `buy_blocked_*` / `down_limit_blocked` 统计。

### L-007 等权 + 乐观成本夸大可迁移性
- **现象**：回测尚可，一加真实滑点/冲击即塌。
- **根因**：仓位忽略波动与相关；成本模型过简。
- **对策**：模块 7（波动/相关/信号强度）+ 滑点与参与率冲击 + 双倍成本晋级门。
- **验收**：正常/悲观/极端成本三套表；双倍成本测试段收益 ≥ 0。

### L-008 监控与死亡线不闭环会重复交学费
- **现象**：失效策略改参「复活」；实盘静默跑输回测。
- **根因**：无 IC 衰减、无 live drift、无永久冻结制度。
- **对策**：模块 9–10；3 个样本外窗口 IR < -0.5 → 永久冻结。
- **验收**：冻结策略名+版本不可复用；复活必须新因子族系 + 全流程预注册。
