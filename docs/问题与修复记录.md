# astock-alpha-new 问题与修复记录

> 项目目录持续追加。每发现一个问题、每落地一次修复，都在此记一条。  
> 状态：`open` / `in_progress` / `mitigated` / `wontfix`  
> 关联规格与回测日志可写相对路径。

---

## 使用规则

1. **新问题插在最上方**（同一轮会话里可先记现象，修好后再补「修复」段）。  
2. 一条只讲一个问题；修复方式写清楚「改了什么 / 刻意没改什么」。  
3. 禁止只改代码不记文档；禁止为救曲线拧参却写成「优化」（L-001）。  
4. 回测混日志导致的误诊，要单独记「诊断口径」问题，避免重复踩坑。

### P-20260811-03 — 五年净值「账面微盈、效率不合格」+ 实现可信度缺陷（审查入库）
- **日期**：2026-08-11  
- **状态**：`open`（资金冻结；纳入六阶段，先做阶段1）  
- **现象（掘金绩效）**：期末约 106.5 万、累计 +6.48%、年化 1.29%、最大回撤 -11.62%、相对 HS300 超额约 +16pp；盈亏比 0.78；最长未创新高约 779 天；年换手约 9.45×；手续费约占净利润 21%。掘金 Sharpe/Sortino=-4.00 与标题指标不相容，疑口径/哨兵值，须自算净值。  
- **根因（已核对代码，按优先级）**：  
  1. **M5 空转**：`pipeline_day.py` 传入 `fin_data_dict={ticker:{}}` 仍跑 shortlist「基本面60%」→ 实质形态排序；`data_fetcher.CACHE_DIR` 仍为 Linux VM 路径。

  3. **区制硬清仓**：BEAR/PANIC 立即清空簿，无确认/迟滞。  
  4. **簿成本≠成交价**：`open_book_lot` 优先 `pos.price`（信号价），未用掘金成交回报。

- **与既有诊断衔接**：SIDEWAYS 前向不差但止损错杀（P-20260811-01）；高低切改造未改成交路径（P-20260811-02）。BULL/trend 前向诊断偏弱，宜冻结。

### P-20260811-01 — SIDEWAYS 票不差但被止损晃下车
- **日期**：2026-08-11  
- **状态**：`mitigated`（代码已落地，待回测复验错杀率）  
- **现象**：最新 HS300 五年回测中 SIDEWAYS 开仓后大量 `stop_loss`；表面像选股失败。  
- **诊断**：重放 26 次 SIDEWAYS 开仓 / 75 只票（`artifacts/sideways_pick_quality.csv`）。入场后均前向 r20≈+3.7%、约 65% 上涨；36 次硬止损里后来 r20>3% 约 18 次、r20<-3% 约 9 次 → **错杀多于砍对**。  
- **根因**：震荡市用短持 + 偏紧止损，与均值回归修复节奏不匹配；板块侧仍偏「单日超跌」而非「跌透+缩量」。  
- **修复方式（已落地）**：方案 B——  
  1. `m2_sector/sector_rotation.py`：SIDEWAYS **高低切** `0.5*z(跌深)+0.5*z(缩量)`，写入 `highcut_scores`；无候选回退单日超跌；  
  2. `stock_selector.py`：mean_revert 加缩量过滤（缺量能不通过）并按跌深/缩量排序；  
  3. `gm_host/runtime.py`：`stop_loss` 后同票 **5 个交易日冷却**；`pipeline_day` meta 记录 `sideways_highcut`。  
- **规格**：`docs/superpowers/specs/2026-08-11-sideways-highcut-exit-design.md`  
- **验证**：`tests/m2_sector/test_sector_rotation_sideways.py` + `tests/test_gm_host_stop_cooldown.py`（5 passed）；完整五年复验待跑。  
- **刻意不做**：放宽止损救五年曲线；提高全样本开仓率；估值分位；改 BULL。
